## Quick Start

```bash
# Regenerate sample files
python examples/generate_samples.py

# Migrate individual files
python migrate.py examples/Enterprise_Sales.wid
python migrate.py examples/Invoice_Report.rpt
python migrate.py examples/eFashion_Universe.unx
python migrate.py examples/Sales_Exploration.lumx

# Batch migrate BIAR archive
python migrate.py --biar examples/Enterprise_Export.biar

# Assessment mode
python migrate.py examples/Enterprise_Sales.wid --assess

# Fabric-native output
python migrate.py examples/Enterprise_Sales.wid --output-format fabric

# Custom output directory
python migrate.py examples/Enterprise_Sales.wid --output-dir /tmp/sales_output
```

## Feature Coverage

These samples collectively exercise:

- **WebI extraction**: ZIP/XML parsing, data providers, variables, prompts, filters, charts, breaks, sorts, alerters, document links, freehand SQL
- **Crystal extraction**: Binary parsing, `{Table.Field}` fields, `{@Formula}` refs, `{?Param}` refs, Group/Sort/Chart/Subreport markers, running totals, conditional formatting
- **Universe extraction**: ZIP with businesslayer.blx + datafoundation.dfx, dimensions, measures, details, joins, contexts, derived tables, LOVs, @Aggregate_Aware
- **Legacy Universe**: Binary UNV with embedded XML blocks
- **Lumira extraction**: ZIP with JSON, datasources, datasets, dimensions, measures, visualizations, pages, calculated fields, filters
- **BIAR batch**: ZIP manifest with embedded .wid/.rpt/.unx artifacts
- **DAX conversion**: In/ForAll/ForEach context operators, RunningSum, If/ElseIf, Previous, DaysBetween, Average
- **Generation**: TMDL semantic model, PBIR v4.0 report, visual mapping, relationship inference, Power Query M
