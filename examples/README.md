# 📦 Example SAP BusinessObjects Artifacts

Synthetic sample files for testing the BOToPowerBI migration pipeline end-to-end.
Generated by `generate_samples.py`.

`desktop_intelligence_export.bas` is a separate, experimental VBA capture
macro, not a synthetic report. Its Desktop Intelligence execution is unverified;
see the main README for its prerequisites, SQL sensitivity and the synthetic
RDL/M handoff.

## Quick Start

```bash
# Regenerate sample files
python examples/generate_samples.py

# Migrate the sample folder (each source receives an isolated output directory)
python migrate.py examples --output-dir examples_pbi

# Batch migrate BIAR archive
python migrate.py --biar examples/Enterprise_Export.biar --output-dir biar_pbi

# Assessment mode
python migrate.py examples/Enterprise_Sales.wid --assess

# Fabric-native output
python migrate.py examples --output-format fabric --output-dir examples_fabric
```

These files are synthetic. Folder generation can return a nonzero exit code for
samples whose datasource is not extracted; check `batch_manifest.json` and
`batch_report.html` rather than treating generated files as fidelity evidence.
In `Sales_Exploration.lumx`, the source connection is not extracted from the
combined metadata, so generation uses a synthetic ODBC placeholder. The four
charts have no declared page or field bindings and are retained on a synthetic
page for review. The SQL of `eFashion_Universe.unx` remains unbound when its
connection metadata is ambiguous and is flagged in the batch report. Explicit
simple universe column references are preserved, but complex select expressions
and filters are not translated. Extracted WebI columns without a table association
are also reported for review. Explicitly associated columns can be retained on a
uniquely named SQL query table, but their names and types are not verified against
the query result schema during local migration.

## Feature Coverage

These samples collectively exercise:

- **WebI extraction**: ZIP/XML parsing, data providers, variables, prompts, filters, charts, breaks, sorts, alerters, document links, freehand SQL
- **Crystal extraction**: Binary parsing, `{Table.Field}` fields, `{@Formula}` refs, `{?Param}` refs, Group/Sort/Chart/Subreport markers, running totals, conditional formatting
- **Universe extraction**: ZIP with businesslayer.blx + datafoundation.dfx, dimensions, measures, details, joins, contexts, derived tables, LOVs, @Aggregate_Aware
- **Legacy Universe**: Binary UNV with embedded XML blocks
- **Lumira extraction**: ZIP with JSON metadata, datasets, explicitly named column tables, visualizations, pages, calculated fields and filters; connection and binding extraction remain partial
- **BIAR batch**: ZIP manifest with embedded .wid/.rpt/.unx artifacts
- **DAX conversion**: In/ForAll/ForEach context operators, RunningSum, If/ElseIf, Previous, DaysBetween, Average
- **Generation**: TMDL semantic model, PBIR v4.0 report, visual mapping, relationship inference, Power Query M
